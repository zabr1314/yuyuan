# 芋圆 YUYUAN 官网

芋圆是一支 AIGC 创作团队，做 AI 广告片、电商视觉、社媒短视频和短剧动画。这个仓库就是官网本身：一个静态单页，不需要构建，用浏览器直接打开 `index.html` 就能预览。

**网址：** https://zabr1314.github.io/yuyuan/

## 目录

| 路径 | 内容 |
| --- | --- |
| `index.html` | 整个网站：结构、样式、脚本和中英文文案都在这一个文件里 |
| `media/` | 视频。`hero-*`、`tile-*`、`v-*` 是首屏和作品区的无声循环片段，`full-*` 是点开后播放的完整版，每个视频都有同名 `.jpg` 封面 |
| `img/` | 案例区图片：山下有松画册、AI 模特图 |
| `logo/` | 品牌图标：SVG 源文件、PNG、社媒头像、网站小图标 |
| `favicon.svg`、`apple-touch-icon-180.png` | 浏览器标签页和手机收藏夹图标 |

## 怎么改

- **改文字**：在 `index.html` 里搜索要改的中文直接改。英文文案在文件后半部分的 `EN` 对象里，按同一个 key 修改。
- **换作品**：视频转成 H.264 编码的 MP4 放进 `media/`（循环片段 5 秒左右、去掉声音；完整版宽 1280px 左右），再把 `index.html` 里对应的文件名换掉。
- **上线前要换掉的占位内容**：联系邮箱 `hello@yuyuan.example`、服务里的「参考周期」、流程里每一步的天数。

改动提交到 `main` 分支后，GitHub Pages 会在一两分钟内自动更新网站。
